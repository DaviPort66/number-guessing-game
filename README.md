# number-guessing-game

Um jogo simples de adivinhação de números, onde a máquina escolhe um numero aleatório entre 1 e 100, e o usuário deve tentar adivinhar baseado nas dicas da máquina.

O usuário pode escolher a dificuldade do jogo, recebendo mais ou menos chances baseado em cada dificuldade.

Caso o número digitado seja maior que o escolhido pela máquina, a máquina avisa que esse número é maior que o escolhido e repete o processo até o usuário acertar ou as chances acabarem
